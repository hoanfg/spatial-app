# Independent Local Moran / LISA validation: Yanqing, Beijing (2020, 500 m)

**Date:** 11 November 2026. **Source:** `CHN_beijing_yanqing_2020_500m_lisa_cells.csv`, exported from spatial-app by the user. **Reference formulas:** repository `hoanfg/spatial-app`, `main` after PR #10, commit `9574cf872c52d266aa15c363df7965cce31601f0`. This is an independent analysis of the exported CSV, **not** a repeat extraction from the original VIIRS raster or a direct ESDA execution.

## Deterministic validation

| Check | Result |
|---|---|
| Rows / cells | 8,333 |
| Boundary cells at area < 0.99 × 0.25 km² | 600; exact agreement |
| Cells included in LISA | 7,733 |
| Queen neighbor matrix, individual neighbor degree comparison | 8,333/8,333 match |
| Raw HH, LL, HL, LH quadrants | 7,733/7,733 match |
| Local Moran I recomputed from exported NTL | Maximum absolute difference 0.00016805 |
| Benjamini–Hochberg at α = 0.05 recomputed from exported `lisa_p_sim` | Exact match, 2,880 cells |
| HH / LL from BH on exported p-values | 370 / 2,510 cells |

Differences in Local I must not be described as algorithmic errors: the CSV's `ntl_mean` and `lisa_I` were rounded, while the original algorithm used unrounded data.

## Independent conditional permutations

- Model: hold the focal observation fixed, sample other observations **without replacement** in each permutation, row-standardize spatial lag by neighbor count, and use ESDA normalization for Local Moran. **999 permutations**, independent seed **20261111**.
- Pseudo-p convention: two-sided, twice the smaller tail plus one, tie tolerance `1e-12`; then BH at `α=0.05`.
- Correlation between independently simulated p-values and application CSV: **0.996736**.
- Mean absolute p difference: **0.015636**; P95 absolute difference **0.058**.
- Number of BH-significant cells: **2,879** (independent) versus **2,880** (app); **179 cells** differ in BH decisions under this seed.

| Cluster | App | Independent | Intersection | Union | Jaccard |
|---|---:|---:|---:|---:|---:|
| High–High | 370 | 375 | 360 | 385 | 0.9351 |
| Low–Low | 2,510 | 2,504 | 2,430 | 2,584 | 0.9404 |

Do not interpret the 179 changed decisions as 179 errors: pseudo-p has Monte Carlo uncertainty, especially near the FDR threshold; exported NTL was also rounded. Attribution would require additional seeds and more permutations. Deterministic tests successfully reproduced the observed structure.

## Remaining limitations

1. No original VIIRS raster, so per-cell zonal/`exactextract` values and monthly `cf_cvg` support have **not** been independently verified.
2. No per-cell GHSL table, so Spearman/AUC/bootstrap were **not** independently recomputed; screenshots represent results **inside the app**.
3. This recomputes formulas from CSV; it is **not** a direct ESDA software benchmark over all 8,333 cells in this session.
4. The export does not contain all hyperparameters or `lisa_method_version`; the configuration was inferred from source code, exported p-values and output. Include regional/configuration metadata in future exports for complete auditing.
