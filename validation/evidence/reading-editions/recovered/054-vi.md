# Hướng dẫn lệnh và bằng chứng

Chạy PowerShell tại không gian làm việc kiểm toán (thư mục cha của thư mục đầu ra này). Các lệnh bên dưới là quy trình cuối cùng đã thành công, được tổng hợp để tái lập. Những lần cài đặt thất bại trước đó vẫn nằm trong nhật ký cài đặt. Quy trình này không thay đổi mã nguồn repository đã ghim commit.

```powershell
$base = (Get-Location).Path
New-Item -ItemType Directory -Force work,outputs | Out-Null
git clone --filter=blob:none --no-checkout --depth 1 --single-branch --branch main https://github.com/hoanfg/spatial-app.git work/audit-repo
git -C work/audit-repo sparse-checkout init --cone
git -C work/audit-repo sparse-checkout set ntl tests docs .github .streamlit data/gadm41_CHN_gpkg
git -C work/audit-repo checkout main
git -C work/audit-repo rev-parse HEAD
# Audited SHA must be 81a53c96eb1405c56665146325383c6e02350dc9.
# If main has changed, explicitly fetch and checkout that SHA before comparing results.
py -3.13 -m venv work/venv
$python = Join-Path $base 'work/venv/Scripts/python.exe'
& $python -m pip install -r work/audit-repo/requirements.txt scipy pytest esda libpysal psutil numba
& $python -m pip check
& $python -m pip freeze
Push-Location work/audit-repo
& $python -m compileall -q app.py ntl tests
& $python -m pytest -vv -ra
Pop-Location
Invoke-WebRequest 'https://geodata.ucdavis.edu/gadm/gadm4.1/gpkg/gadm41_CHN.gpkg' -OutFile work/gadm41_CHN.gpkg
Invoke-WebRequest 'https://geodata.ucdavis.edu/gadm/gadm4.1/json/gadm41_CHN_3.json.zip' -OutFile work/gadm41_CHN_3.json.zip
& $python outputs/audit_harness.py gadm raster numeric
& $python outputs/gadm_source.py
& $python outputs/schema_check.py
& $python outputs/moran_n30.py
& $python outputs/ui_clicks.py
& $python outputs/quality_ui_click.py
& $python outputs/ee_probe.py
& $python outputs/benchmark.py
& $python outputs/municipality_benchmark.py
git -C work/audit-repo diff --exit-code
git -C work/audit-repo diff --cached --exit-code
git -C work/audit-repo status --porcelain=v1
git -C work/audit-repo ls-remote origin refs/heads/main
```

Các chương trình kiểm thử trong `outputs` có thể chạy trực tiếp tại không gian làm việc này. Chúng tìm thư mục gốc ở cấp cha và dự kiến bản sao repository cùng môi trường ảo nằm trong `work`. Chúng ghi tệp kết quả vào `outputs`; chạy lại có thể ghi đè kết quả cũ. Báo cáo mô tả lần chạy gốc có ngày cụ thể, không tự cập nhật nếu chỉ chạy lại từng chương trình. Để tái lập đúng môi trường gói, dùng `environment-freeze.txt` thay vì cài lại các phiên bản phụ thuộc mới nhất.

Nhật ký của lần chạy thực tế:

- `pytest-full.log`: toàn bộ 36 bài kiểm thử, gồm nhập thư viện raster thật và Streamlit, không bỏ qua bài nào.
- `dependency-install.log`, `requirements-install.log`, `requirements-retry.log`: các lần cài gói và lần chạy lại thành công. Lần cài requirements đầu trùng các tác vụ pip đang chạy nên gặp khóa tệp Windows; lần thử tuần tự sau đó thành công.
- `gadm-raster.log`: bước kiểm GADM sơ bộ và kiểm thử raster độc lập. So sánh sơ bộ với GeoJSON giản lược đã được thay bằng `china-gpkg-validation.json` và `china-schema-validation.json`. Số tên `NAME_1` không khớp thô phản ánh ánh xạ lại lược đồ, không phải mất quận/huyện.
- `china-gpkg.log`: đối chiếu GADM đầy đủ độ phân giải, có tính thẩm quyền trong đợt kiểm này.
- `moran-comparison.log` và `moran-n30-exact.log`: đối chiếu số học, phân phối không chính xác.
- `ui-clicks.log` và `quality-ui-click.log`: các lượt AppTest bổ sung. Có thể có cảnh báo Streamlit dự kiến về API sắp ngừng hỗ trợ/chế độ chạy không đầy đủ; kết quả nằm trong JSON tương ứng.
- `earth-engine-probe.log/json`: kiểm tra thành công kết nối mạng và tình trạng chưa được cấp quyền xác thực.
- `ram-benchmark.log/json`: bộ theo dõi bộ nhớ toàn cây tiến trình đã sửa; khối lượng xử lý raster tổng hợp.
- `municipality-grid-benchmark.log/json`: khối lượng tạo lưới từ hình học đô thị thực và cơ chế bảo vệ với Trùng Khánh.
- `final-checks.log`: kiểm tra nhất quán phụ thuộc, biên dịch, commit và đối chiếu `main`. Python tạo các thư mục `__pycache__` chưa được theo dõi trong khi kiểm thử; không sửa tệp nguồn nào đang được Git theo dõi.

Mã băm nguồn và kết quả được cung cấp trong gói. GADM nguồn và bản sao repository nằm trong `work`, ngoài ZIP bằng chứng. ZIP chứa báo cáo, lệnh, chương trình kiểm thử, bảng kết quả thô, nhật ký và thông tin môi trường, không chứa repository lớn hoặc môi trường ảo.
