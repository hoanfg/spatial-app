# Validation report: NTL spatial econometrics

11 November 2026. Author recorded in the original: @hoang le.

## Conclusion

**The computational logic was tested using simulated data; no tests were performed on real satellite data.** Thirty-two tests passed, two were skipped locally for missing libraries, and GitHub CI was green on the then-current `main`. No external benchmarking against other software or published results was conducted.

- **Validated:** syntax, 32 logic tests on synthetic data, green CI, and correspondence of the `main` code with the tested source (except for one user-interface heading).
- **Not validated:** the Earth Engine data download code (monthly counts and GHSL), new panels after clicking their buttons, performance or the 1 GB RAM claim in README, and interpretation thresholds.
- **Research implication:** do not cite tool-generated quantities as empirical evidence until a real region has been processed and independently compared (Sections 4 and 5).

## Benchmarks and thresholds used

**There was no external benchmark.** None of the reviewed commands compared against PySAL/esda or GeoDa (`esda` and `libpysal` were unavailable), published results, runtime or memory. Tests were internal correctness tests: mathematical invariants (e.g., T07 permutation invariance of centered averages), degenerate cases (all-dark, constant values, isolated components), and seed stability.

The thresholds below are **practical conventions hardcoded in the source, not calibrated against data or literature**:

| Threshold | Value | Purpose |
|---|---|---|
| Median Jaccard across variants | ≥ 0.70 "robust"; ≥ 0.50 "moderate"; otherwise "weak" | High-High cluster robustness summary |
| "Robust core" | HH in the original and at least 80% of runs | Stable area |
| Spearman ρ versus GHSL | ≥ 0.60 "strong"; below 0.40 "weak"; at least 30 core cells required | External agreement |
| Block bootstrap | 200 replicates; blocks of 5×5 cells | Confidence interval for ρ |
| Data quality warnings | Negative pixels > 10%; any NaN pixel; zero cells > 50% (informational); pixels with zero observed months > 1%; pixels with fewer than three months > 20% | Data Quality panel |
| Negative clipping versus retained negatives | Warn if ρ < 0.98 or changed-cell share > 10% | Sensitivity to negative values |
| Minimum attainable p-value | 2 / (number of permutations + 1) | With few permutations and FDR, clusters may never be rejected (observed with 199 permutations) |

For publication, label these as reference descriptive thresholds and report each Jaccard rather than only "robust".

## Tests with real data

**None.** No reviewed command used real VIIRS imagery, GHSL data or GADM boundaries.

- **Test data** were generated in code using `numpy.random.default_rng` with fixed seeds (except `test_zonal`, which creates a tiny GeoTIFF in memory).
- **`test_zonal`** uses real libraries (rasterio, exactextract) on a constructed 2×4-pixel image; it only ran in CI.
- **`test_ui_smoke`** runs the UI through `AppTest` on synthetic data, without calling Earth Engine. It checks that LISA displays without error and contains a diagnostics panel; it does not click buttons.
- The **`data/` directory** has GADM boundaries for 35 countries but no test reads them.
- **Network:** the local environment could not reach Earth Engine and had no credentials.

The user had run the real application at `spatial-app.streamlit.app` and provided UI screenshots. These demonstrate that the app runs, but no visible values from the screenshots were compared against an independent source in this report.
